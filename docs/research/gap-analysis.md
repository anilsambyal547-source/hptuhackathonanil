| **1.1** | **Raw Text & Screenshot Input** | **MET** | `components/ScannerInput.tsx` lines 30-80 supports both text paste and drag-drop file uploads. | None. | Fully implemented. |
| **1.2** | **Clipboard Paste (`Ctrl+V`)** | **MET** | `components/ScannerInput.tsx` lines 45-65 has global `window.addEventListener("paste")` handler. | None. | Fully implemented. |
| **1.3** | **OCR for Screenshots** | **PARTIAL** | `app/api/ocr/route.ts` uses Gemini Vision multimodal API. | If `GEMINI_API_KEY` is not provided or rate-limited, there is no client-side Canvas/OCR fallback. | Add client-side Canvas OCR text pre-filter and fallback image preprocessor (`lib/ocr/canvas-ocr.ts`). |
| **1.4** | **Degraded / Blurry Image Graceful Handling** | **MET** | `lib/ocr/image-quality.ts` evaluates resolution (< 640px), compression artifacts (< 15KB), and emits explicit warnings. | Warning is visible, but should provide a dedicated image enhancement / re-upload recommendation card. | Add interactive Image Quality Card in `components/ScannerInput.tsx`. |
| **2.1** | **Multi-Method Detection (Not single AI)** | **MET** | `lib/engine/pipeline.ts` combines Heuristics + Passive URL + Impersonation + Contextual AI + Decision Fusion. | Signals weighted, but hard indicators could be diluted in edge cases. | Introduce **Hard Confidence Floors** (inspired by ScamIntelli) for critical threats (e.g. OTP theft, CBI digital arrest). |

| **2.3** | **Sensitive Credential Solicitation** | **MET** | `lib/engine/heuristics.ts` lines 15-70 detects OTP, PIN, CVV, NetBanking, PAN/Aadhaar, AnyDesk. | Anti-phishing educational advice could occasionally be triggered without full negation window. | Refine `ADVISORY_NEGATION_REGEX` to check broader contextual sentences. |
| **2.4** | **Direct Payment & UPI Solicitation** | **MET** | `lib/engine/heuristics.ts` lines 130-170 regex checks 12+ UPI banking handles (`@okhdfcbank`, `@paytm`, etc.). | Does not flag deceptive **UPI QR Code payment bait** ("scan this QR to receive cashback"). | Add QR code bait regex and deceptive refund solicitation rules. |
